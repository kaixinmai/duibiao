# 白绿平台 · 视觉规范（合作方 UI Kit）

问答详情 Shell 统一白绿企业级风格。合作方 **只挂载本 Kit CSS**，不改布局与交互结构。

## 禁止修改项（结构锁定）

- 左右分栏比例与 DOM 结构（`.cta-shell` / `.cta-history` / `.cta-main`）
- 底部输入框结构、工具栏按钮布局与尺寸
- 新建会话 / 历史列表 / 返回 / 滚动遮罩的交互逻辑

## 色彩体系

| 用途 | 色值 |
|------|------|
| 页面底色 | `#f5faf7` / `#eef6f1` |
| 卡片 / 侧栏底 | `#ffffff` |
| 模块浅底 | `#f0f8f4` / `#ddf8eb` |
| 主色（功能高亮） | `#00b86b` |
| 主色悬停 | `#00995a` |
| 辅色 | `#22c7a3` / `#7ad9b3` |
| 边框 | `#d8ece2` |
| 主文字 | `#101828` |
| 正文 | `#475467` |
| 辅助文字 | `#98a2b3` |
| 危险 / 警告 | `#f04438` / `#f79009` |
| 渐变强调 | `linear-gradient(90deg, #00b86b, #22c7a3)` |
| 阴影 | `rgba(0, 184, 107, 0.08)` |

> 历史深空科技色（`#070E20` / `#40A8FF` / `#1890ff`）已废弃。

## CSS 变量

挂载 `theme-green.css` 后可用：

- `--gc-primary` / `--gc-secondary` / `--gc-soft` / `--gc-bg`
- `--gc-text` / `--gc-text-body` / `--gc-text-muted` / `--gc-border`

## 模块规范

### 左侧栏

- 返回：白底浅绿边，hover 主色
- 标题：`#101828`，禁止荧光描边 / 渐变透明字
- 新建会话：浅绿底 + 主色字
- 历史：默认 `#475467`；选中浅绿底 + 主色

### 右侧主区

- 欢迎区：正文深色；强调字实心主绿（禁止 clip 透明字反绿）
- AI 气泡：白底 + 浅绿描边
- 用户气泡：浅绿玻璃底 + 深色字
- 相关问题 / FAQ 芯片：白底深字，hover 浅绿

### 输入区

- 白底、`#d8ece2` 边；focus 主色环
- 发送钮：实心 `#00b86b`，白字

### 思考块 / 指标卡

- 白底绿边；正文 `#475467`
- 正向指标 `#00b86b`；警告 `#f79009`；风险 `#f04438`

## 作用范围

| 页面 | 是否挂载 Kit |
|------|----------------|
| 问答详情 `index.html`（cta-shell） | ✅ 必须 |
| dashboard / business / 报告系统 | ❌ 不要挂 |
