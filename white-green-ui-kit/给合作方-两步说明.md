# 给人看的最短说明（转合作方）

## 你们要做的只有两步

1. **把文件夹放进项目**  
   将整个 `white-green-ui-kit` 解压/拷贝到智能体 dist 根目录（和问答页 `index.html` 同级即可）。

2. **交给 Cursor**  
   打开 Cursor → 打开该项目 → 把  
   [`CURSOR-一键挂皮提示词.md`](./CURSOR-一键挂皮提示词.md)  
   里「↓↓↓ 复制」到「↑↑↑」之间的整段话贴进 Chat → 发送。  
   让 Cursor 自己跑脚本 / 改 HTML，**不要自己手改三行 link**。

做完用浏览器打开问答 `index.html` 看是不是白绿色；`dashboard` 业务页不用管。

---

若没有 Cursor：在 dist 根目录执行一次：

```bash
node white-green-ui-kit/tools/apply.mjs --root .
```
