数据对标智能体 — 页面组件包
========================================

【发给同事怎么用】
  1. 解压 zip
  2. 进入文件夹，安装依赖并启动：
       npm install
       npm run dev
  3. 浏览器访问终端显示的地址（默认 http://127.0.0.1:5173/）
  4. 也可将整个文件夹复制到对方项目的 public/ 或 static/ 目录，用静态服务器访问 index.html

【本包包含】
  • 完整页面 HTML / CSS / JS
  • 内置 ECharts，无需联网下载
  • 河南钢铁集团演示数据与多维对标分析功能
  • 钢铁企业智能对标分析报告（内测 1.1 格式）
  • 报告出品：佳华智联 · 数据对标智能体
  • 重点工序对标口径：烧结工序 + 炼铁工序
  • 演示周期：2026年6月（报告统计周期 2026.6.1-6.30）

【演示示例】
  输入：查询2026年6月河南钢铁集团钢铁行业全国排名
  完成后点击「查看对标分析报告」预览新版报告
